# 國二英文每日任務 + 零用金系統

每個平日（週一～週五）晚上 8:00，由 claude.ai 排程（Routine）自動生成一篇**國二（grade 8）英文閱讀測驗**，
內含 10–20 個目標單字與 2–3 個文法概念，共 **10 題（5 閱讀 + 5 文法/單字）**。

## 零用金機制
- 學生把答案回覆給 Claude → 批改；**答對 ≥ 8/10** 當日獲得 **100 元**。
- 每月約 20 個平日 → 約 **2000 元/月**。
- 每月可兌現一次；**未領取的餘額按年利率 10%、每月複利滾存**。
- 帳本＝[`零用金帳本.md`](零用金帳本.md)，每日測驗存於 [`daily/`](daily/)。

## 規則細節
見 [`每日任務規則.md`](每日任務規則.md)。Claude（排程或對話）皆依此檔運作。

## 使用方式
1. 平日 20:00 排程自動生成當日測驗（也會顯示零用金看板）。
2. 學生作答後，在對話中回覆 10 題答案 → Claude 批改、達標入帳、更新帳本。
3. 每月想領錢時，說「領取零用金」即可兌現。
